# ANDANTINO 本公開チェックリスト

## 1. ドメインと公開先

- [ ] `andantino-shoes.jp` が五十嵐洋子名義のValue-Domainアカウントへ譲渡済み
- [ ] Cloudflare Pagesへ `www.andantino-shoes.jp` を接続済み
- [ ] ルートドメインからwwwへ正しく転送される
- [ ] HTTPS証明書が有効
- [ ] 旧サイト停止前に新サイトが独自ドメインで表示される

## 2. 検索エンジン

- [ ] canonicalが本番ドメインを指している
- [ ] `npm run indexing:live` を実行した
- [ ] HTMLのrobots metaからnoindexが消えている
- [ ] HTTPレスポンスの`X-Robots-Tag`からnoindexが消えている
- [ ] `robots.txt` と `sitemap.xml` が表示される
- [ ] Google Search Consoleへ登録しsitemapを送信した
- [ ] Bing Webmaster Toolsへ登録しsitemapを送信した
- [ ] IndexNowを実行した

## 3. 旧サイトからの移行

- [ ] 旧URL一覧を確認した
- [ ] 主要旧URLから新URLへの301リダイレクトを確認した
- [ ] 404ページを確認した
- [ ] GoogleビジネスプロフィールのURLを更新した
- [ ] LINE、Facebook、ブログ、YouTube等の公式サイトURLを更新した

## 4. 店舗情報の一致

- [ ] 店名
- [ ] 住所
- [ ] 電話番号
- [ ] 営業時間・定休日
- [ ] 予約制の範囲
- [ ] 支払方法
- [ ] カウンセリング料金
- [ ] インソール料金
- [ ] オンライン相談料金・所要時間

本文、フッター、FAQ、料金ページ、構造化データで一致していることを確認します。

## 5. 予約導線

- [ ] LINEボタンが開く
- [ ] 電話リンクが発信画面を開く
- [ ] メールリンクが正しい
- [ ] LINE用の大人・子ども・インソールの相談ひな形をコピーできる
- [ ] 問い合わせフォームを使う場合は実際に送信テストした
- [ ] スマートフォン下部のクイックアクションが本文を隠さない

## 6. 表示と安全性

- [ ] 代表的なAndroid端末で確認
- [ ] iPhone相当の幅で確認
- [ ] PCで確認
- [ ] 主要画像の人物・靴が見切れていない
- [ ] リンク切れがない
- [ ] 管理画面へのリンクが一般向けメニューに出ていない
- [ ] `/admin/` が認証なしで操作できない
- [ ] SupabaseのRLSが有効
- [ ] 公開不要な`docs/`、設定ファイル、秘密情報へアクセスできない
- [ ] APIキーやパスワードがリポジトリへ入っていない

## 7. 引き渡しテスト

洋子さん本人のアカウントから、次の3つを実施します。

- [ ] 写真を1枚変更し、プレビュー確認後に公開
- [ ] 営業時間または文章を変更し、全ページの矛盾を確認
- [ ] 記事を下書き作成し、確認後に公開

3つを本人だけで完了できた時点を運用引き渡し完了とします。
