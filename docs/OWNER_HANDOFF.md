# ANDANTINO 店主向け更新ガイド

## 普段使う依頼は4種類だけ

五十嵐洋子さんは、ChatGPT/Codexへ次のように伝えれば更新できます。

### 写真を変更する

> トップページの○○の写真を、添付した写真へ変更してください。人物や靴が見切れないように調整し、公開前に変更内容とプレビューを見せてください。

### 営業時間や料金を変更する

> 営業時間を○○へ変更してください。サイト内に同じ情報が書かれているページと構造化データも確認し、矛盾が出ないようにしてください。公開前に変更箇所を一覧で見せてください。

### お知らせを掲載する

> 次の内容をお知らせとして掲載してください。日付、タイトル、本文を整え、公開前に全文を確認させてください。

### 記事を掲載する

> この会話をANDANTINOのお役立ち記事にしてください。医療効果を断定せず、店主の経験と靴店として確認できる範囲を分けて書いてください。下書きで作成し、全文確認後に公開してください。

## 自分で変更してよい範囲

- 写真
- 文章
- 営業時間
- 料金
- 商品・サービス情報
- お知らせ
- お役立ち記事
- 相談事例（本人の掲載許可があるもの）

## 必ず確認してから変更する範囲

- ドメイン、DNS、Cloudflare
- URL、ファイル名、リダイレクト
- canonical、robots、sitemap、構造化データの仕組み
- GitHub Actions、ビルド設定
- Supabaseの認証・RLS・データベース構造
- 全ページへ影響するデザイン変更

## 公開前の確認

1. 変更内容の説明を読む
2. プレビューをスマートフォンで見る
3. 料金、営業時間、連絡先に間違いがないか確認する
4. 写真が見切れていないか確認する
5. LINE・電話・各リンクを押して確認する
6. 問題がなければ公開する

## 管理画面

管理画面は一般向けメニューには掲載しません。URLをブックマークして使用します。

- オンライン相談の受付設定
- PDF商品の公開設定

記事や通常ページの更新は、ChatGPT/Codexから行います。

## 困ったとき

エラーが出た場合は、同じ操作を繰り返さず、表示されたエラー画面をスクリーンショットでChatGPTへ送ってください。ドメイン・DNS・Cloudflareの設定は、判断せずに管理担当者へ確認します。
