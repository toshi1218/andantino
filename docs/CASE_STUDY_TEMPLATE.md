# 相談事例の作成ひな形

実在するお客様の事例だけを使用し、掲載前に本人または保護者の許可を得ます。氏名、住所、勤務先、学校名、顔写真など、本人を特定できる情報は許可がない限り掲載しません。

## 事例タイトル

例：長時間歩くと足が疲れる方の靴選び

## 1. ご相談内容

- 年代またはお子さまの年齢層
- どのような場面で困っていたか
- 使用していた靴の種類

## 2. 店頭で確認したこと

- お話を伺って確認した生活・用途
- 足のサイズと形
- 今履いている靴の状態
- 立ち方・歩き方

医療的な診断は書かず、靴店として実際に確認した内容に限ります。

## 3. ご提案したこと

- 靴の種類や選び方
- 履き方
- インソールや調整の有無
- 家庭で確認するポイント
- 医療機関等への相談を案内した場合は、その旨

## 4. その後

お客様から実際に伺った感想や、再来店時に確認できた内容だけを書きます。結果を誇張せず、「治った」「必ず改善する」などの断定は避けます。

## 5. 注意書き

> 本事例は一例です。足の状態、生活環境、使用する靴によって提案内容は異なり、同じ結果を保証するものではありません。

## 公開前チェック

- [ ] 掲載許可がある
- [ ] 本人を特定できる情報を不用意に含んでいない
- [ ] 医療診断や治療効果を断定していない
- [ ] 実際に確認・提案した内容だけを書いている
- [ ] 料金や商品名が現在のサイト情報と一致している
- [ ] 写真の使用許可がある
